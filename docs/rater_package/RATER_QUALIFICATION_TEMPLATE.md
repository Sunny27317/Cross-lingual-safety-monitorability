# Rater qualification record — one per rater, completed before training

**Steward completes this before a rater sees any real study material.** No rater is
recruited or invented by this template; every field is filled from a real conversation
with a real candidate.

## What is NOT sufficient on its own

- Citizenship or nationality alone.
- Self-report with no example or conversation to verify it.
- Having previously used a translation tool for Urdu text.
- General AI/CS expertise with no demonstrated Urdu reading competence — technical
  background is optional for this task, not a substitute for language competence.
