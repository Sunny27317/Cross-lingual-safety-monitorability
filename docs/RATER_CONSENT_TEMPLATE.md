## What this study is about

We are studying whether an automated system can correctly tell, from a short piece of
AI-generated text, whether the text openly says it was influenced by a hint it was
given. You will provide your own independent human judgment on the same texts, so we
can compare it to the automated system.

## What you will be asked to do

You will read a set of short, anonymized text passages generated by an AI language
model and select one of five labels for each, describing whether the text discloses
reliance on a hint. You will not interact with the AI model directly. Full task
description: `docs/rater_package/RATER_INSTRUCTIONS.md`, provided separately.
