================================================================================
4. Quantization selection (recorded BEFORE download)
================================================================================

Selected: Q8_0

Neutral priority order (as instructed): Q8_0 > Q6_K > Q5_K_M > Q4_K_M.

Q8_0 was selected because:
  - it IS officially available (the official `Qwen/Qwen3-1.7B-GGUF` repo's ONLY
    published quantization is Q8_0 -- there is no Q6_K/Q5_K_M/Q4_K_M variant from Qwen
    itself in that repo; a third-party quantizer would have been needed for a lower
    precision, which was explicitly de-prioritized per instruction)
  - the file size (1.83 GB) comfortably fits this machine's 32 GB RAM with wide margin
  - Q8_0 is a long-standing, universally-supported GGUF quantization type; no known
    llama.cpp v0.4.0 compatibility issue
  - Reason (as instructed): Q8_0 minimizes quantization distortion relative to the
    full-precision weights while still being very small relative to available RAM.

No scientific behavior was compared across quantization levels to make this choice --
only file availability, size, and compatibility were consulted, before any download.
