7. Non-fatal warnings observed during configure (recorded verbatim intent)
================================================================================

The following were emitted during `cmake -B build` and did NOT prevent the Gate-A
build from completing successfully. They are recorded for provenance; no claim is made
here about their significance for any later stage:

  - "Warning: ccache not found" — build cache absent; affects compile speed only.
  - "OpenMP not found" (x3: OpenMP_C, OpenMP_CXX, OpenMP) — the ggml CPU backend uses
    its own threading / Grand Central Dispatch instead.
  - "OpenSSL not found ... HTTPS support disabled" (vendor/cpp-httplib) — affects only
    the bundled llama-server's HTTPS listener; not relevant to llama-cli.
  - "Performing Test GGML_COMPILER_SUPPORTS_FP16_FORMAT_I3E - Failed" — a compiler
    capability probe; the build proceeds via the alternate FP16 path.
  - "ARM -march/-mcpu not found, -mcpu=native will be used" — native CPU targeting
    was selected instead of an explicit -march.
  - "GGML_MACHINE_SUPPORTS_sve - Failed" / "nosve - Success" — this CPU does not
    implement ARM SVE (SME IS supported and was enabled: -mcpu=native+...+sme).
