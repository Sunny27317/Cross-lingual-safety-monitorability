# Workshop-v1 metadata release scaffold

This directory is intentionally metadata-only. It contains no OpenBookQA item
text, raw traces, translations, reviewer identity, human labels, model
binaries, credentials, or scientific result values.

The eventual release may add approved ID/hash manifests, schemas, code and
provenance after license, privacy and institutional review. Restricted assets
must be requested from their upstream providers or handled through an approved
private archive.
