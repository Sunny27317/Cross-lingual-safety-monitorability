# results/

Computed outputs of **actually executed** experiments only.

## Rules — read before adding anything here

- **No fabricated result data, ever.** No hand-constructed, hand-edited, or
  model-synthesized numbers (see `CLAUDE.md` §2.2).
- Nothing in here unless it was produced by a real run of code in `src/` over
  real data in `data/`.
- Every result file records which experiment/config/commit produced it.
- Negative and null results are kept and reported with equal prominence
  (`CLAUDE.md` §2.4).
- No cherry-picking of seeds, models, languages, items, prompts, or metrics
  (`CLAUDE.md` §2.5).

This directory is currently empty and must stay empty until Milestone 1 produces
real output.
