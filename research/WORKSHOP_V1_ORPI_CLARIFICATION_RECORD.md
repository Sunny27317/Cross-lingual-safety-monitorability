# ORPI clarification record (Workshop-v1; 2026-10-07)

**No determination has been received.** This record states the planned human stage
accurately, for use only if ORPI asks follow-up questions. Do not send it unprompted. It
does not claim exemption or approval.

| Topic | Planned practice |
|---|---|
| Interaction | Raters and the adjudicator interact with the researcher, to receive instructions, the tutorial and the packet, and to submit labels. There is no other interaction and no deception |
| Qualification data | Minimal: how Urdu reading competence is established (first language, Urdu-medium schooling, or daily reading), the synthetic screener result, and a conflict-of-interest confirmation |
| Identifiers | Analysis uses pseudonyms (R1, R2, ADJ) only. Names and contact details are stored separately, used only for administration and payment, and deleted afterwards |
| Urdu qualification | Native or near-native written-Urdu reading, plus enough English to follow instructions, checked by the screener |
| Compensation | If adopted: an identical amount per completed packet for both raters (amount `[TBD]`), or unpaid, stated as such |
| What is research data | The raters' labels (5 categories), yes/no uncertainty flag, optional confidence and optional notes about the AI-generated text. These are judgments about text, not information about the raters |
| Not collected | Demographics, opinions about themselves, health, financial or other private data |
| Content | AI-generated explanations of grade-school science-quiz answers, with a suggestion sentence. No personal data; nothing sensitive expected; `abstain` lets a rater skip anything |
| Publication | Aggregate results will be published. Individual pseudonymous labels only if ORPI permits and each rater consents in writing. No one is named without written consent |
| Start condition | **No human annotation, recruitment message or consent request will begin until ORPI's written determination is received and saved** |
| Prior reviews | A native reader reviewed the item translations (written) and the cue and instruction wording (verbal) before the request. These were reviews of study materials, not of model outputs. This was described in the original request |
