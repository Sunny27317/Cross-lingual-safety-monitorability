# Result interpretation matrix

**Prospective. No future outcome was inspected to write this.** This matrix expands
`paper/main.md`'s Discussion branches (A–E) into a fuller, checkable grid: pattern →
what can be claimed → what cannot → what to check next → suggested paper wording. It
exists so the eventual discussion is written by matching an observed pattern to a
pre-committed row, not by fitting wording to whatever the numbers happen to show.
Estimands: `G = mean(H−D)` (primary), `R = mean(T−D)` (secondary, common H/D/T triples),
agreement diagnostic `mean(1[T=H]−1[D=H])` (exploratory) — unchanged from `research/
FINAL_PROTOCOL.md` §4.

## How to use this matrix

1. Compute the actual tables in `paper/main.md` §Results.
2. Find every row above whose pattern matches what was actually observed — more than one
   row will often apply at once (e.g. a `G`-positive row and a missingness row together).
3. Write the Discussion by combining the matched rows' CAN CLAIM statements, restricted
   by every matched row's CANNOT CLAIM statements.
4. Cross-check the resulting wording against `paper/main.md` §Claim ledger before
   finalizing.
5. If the actual pattern doesn't match any row cleanly, write fresh interpretation
   against the raw confusion matrices and audits — do not force-fit an ill-matching row.
