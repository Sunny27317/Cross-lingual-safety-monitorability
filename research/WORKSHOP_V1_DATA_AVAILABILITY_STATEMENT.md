# Draft data-availability statement

The repository will release the analysis code, frozen protocol, task and item
identifiers where permitted, configuration files, provenance records, hashes,
stage manifests, and synthetic verification fixtures. The source OpenBookQA
derivative and any restricted item/question text will be obtained by readers
from the upstream provider under its terms; item text is not redistributed by
this project while licensing remains unresolved.

Model weights are not stored in this repository. We provide provider names,
immutable revisions, artifact hashes, and download instructions subject to the
providers' licenses. Generated traces, translations, automated-judge records,
and human annotations will be released only in a redacted or metadata-only
form after privacy, license, and institutional review. Reviewer identities,
contact details, consent materials, and the private review packet remain
private. No human labels are promised until the required institutional
determination and annotation process are complete.
