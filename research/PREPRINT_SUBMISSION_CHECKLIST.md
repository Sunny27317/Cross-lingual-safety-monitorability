# Preprint upload checklist (Workshop-v1)

Requirements specific to a server or venue are deliberately **not** asserted here.
Before uploading, read the chosen server's current submission policy, including:
- format and source requirements;
- licence options;
- AI-assistance disclosure;
- category/endorsement rules;
- file-size limits.

Record the date you checked it.

## Manuscript
- [ ] Converted from `paper/WORKSHOP_V1_PREPRINT.md` to the upload format (e.g. LaTeX or
      PDF); it compiles cleanly, with no unresolved references or `??`.
- [ ] **Zero remaining `[[R-…]]`, `[[PENDING…]]` or `[[CITE…]]` markers.** Checked by
      text search.
- [ ] All HTML comments and internal pointers removed (`research/…` paths, slot IDs,
      ledger row IDs).
- [ ] Inactive Discussion paragraphs deleted; activation recorded against the decision
      tree.
- [ ] Title chosen after results. It contains no directional claim the results do not
      support.
- [ ] Spelling and grammar pass; consistent terminology (rationale, trace, monitor,
      judge, native-reader reference, G, AG, R, R_full).
- [ ] Numbers in the abstract, text and tables agree exactly.

## Figures and tables
- [ ] F1–F4 and T1–T8 plus appendix tables are generated by the frozen analysis code.
      The script and commit are recorded.
- [ ] Every figure shows intervals; no figure pools models; axes are labelled;
      colour-blind-safe palette.
- [ ] Every table states its denominators. Missing and undefined values are shown as
      such.

## Authors and front matter
- [ ] Names, affiliations and emails confirmed in writing by each author. No Harvard
      affiliation. No supervision claim without written confirmation.
- [ ] Contributions (CRediT), acknowledgments (names only with consent), funding,
      competing interests.
- [ ] AI-assistance disclosure per the server's policy.

## References
- [ ] Only VERIFIED entries from `literature/WORKSHOP_V1_CITATION_AUDIT.md`. Every NEEDS
      VERIFICATION and PLACEHOLDER entry resolved or removed.
- [ ] Fresh literature check for closer work published since the last audit; dated.
- [ ] Each citation supports exactly the content attributed to it.

## Supplementary material
- [ ] Appendices A–K complete: verbatim prompts (EN/UR), Judge V2 prompt, rater
      materials, hash table, missingness cascade, confusion matrices, sensitivity
      analyses, data dictionary, segmentation and audit, decision record, incident
      record.
- [ ] The Urdu text in the appendices renders correctly (right-to-left; font embedded).

## Licences and data
- [ ] Preprint licence chosen.
- [ ] Dataset text **not** redistributed (licence ambiguous). Only IDs, revision and row
      hashes.
- [ ] Model licences for Qwen3, Gemma 3, Falcon-H1 and IndicTrans2 checked for any
      output-release conditions. Record what was checked.
- [ ] Release scope for model outputs, judge outputs and rater labels matches the
      consent and ORPI terms.

## Code and data links
- [ ] Repository and archive links resolve. The archived commit equals the commit cited
      in Methods.
- [ ] The repository contains no secrets, credentials or personal data. Rater identities
      are pseudonymous.

## Anonymization
- [ ] Not needed for a standard preprint. If a double-blind venue is planned later,
      prepare a separate anonymized version and do not post it from identifiable
      accounts during the review period, if that venue's policy requires it (check the
      policy).

## Integrity audits
- [ ] **Claim audit:** every results, discussion, abstract and conclusion sentence maps to
      a ledger row whose minimum result holds. The tripwire phrase search is clean.
- [ ] **Provenance review:**
      - stage hashes present (generation, direct judge, translation, translated judge,
        human, analysis);
      - authorization files exist for each executed stage;
      - errata recorded (`population_role`, misdated records, the 1.84 h pause, executed
        code commit);
      - ORPI determination quoted verbatim.
- [ ] Negative and null results reported with the same prominence as positive ones.
- [ ] Everything exploratory is labelled exploratory. Anything post-hoc is labelled and
      dated.
- [ ] Final read by the investigator, and by a second reader if available.
